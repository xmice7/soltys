# Soltys — Преміальний комерційний лендінг для освітнього центру / репетиторів

Сучасний, ультрашвидкий та високонверсійний односторінковий сайт (Landing Page) для онлайн-школи, репетиторського центру або підготовки до НМТ / ДПА.

Розроблений за найвищими стандартами сучасного веб-дизайну (EdTech 2026): чистий ванільний HTML5, CSS3 та JavaScript без жодних важких бібліотек чи фреймворків. Завантажується за 0.3 секунди, має 100% адаптивність під усі типи пристроїв (смартфони, планшети, лептопи, 4K-монітори).

## 🚀 Як налаштувати під власний бізнес (за 5 хвилин)

Усі основні контакти та тексти легко змінюються у файлі `index.html`:

### 1. Зміна контактів:
- **Номер телефону**: знайдіть рядок `0 800 33 00 00` (або `tel:+380800330000`) та замініть на свій.
- **Telegram**: знайдіть посилання `https://t.me/soltys_online` та замініть `soltys_online` на нікнейм вашого каналу чи менеджера.

### 2. Редагування назви та логотипу:
- Пошукайте слово `Soltys` — ви можете змінити його на будь-яку назву вашого центру або школи в один клік (через масовий пошук та заміну).

### 3. Підключення відправки заявок:
Зараз у формах реалізована перевірка даних (валідація телефону й імені) та показ гарного екрану успіху. Щоб ліди надходили прямо вам у Telegram:
- Використайте Telegram Bot API (метод `sendMessage`), додавши 5 рядків fetch-запиту в функцію `handleForm` у блоці `<script>`.
- Або підключіть будь-який сервіс форми (Formspree, Make, Zapier, Webhook CRM).
